# Bug 本地记录模板

将以下模板追加到用户级 `bug-fixes.md`，不要放入项目目录。编号使用 `BUG-YYYYMMDD-NNN`，同一天从 `001` 顺序递增。

```md
## BUG-YYYYMMDD-NNN：简短标题

- 处理类型：新建 / 追加 / 调整
- 状态：已修复 / 部分修复 / 待验证 / 未解决
- 发现日期：YYYY-MM-DD
- 最近更新：YYYY-MM-DD
- 仓库唯一标识：remote-<64位哈希> / path-<64位哈希>
- 标识来源：规范化远程 URL / Git 根目录或工作区路径兜底
- 当前工作树：仅记录必要路径，不记录凭证
- 用户提供问题描述摘要：
- 详细设计/其他物料摘要：无 / ...
- Git 未提交代码分析：无 / ...
- 现象：
- 复现步骤：
  1. 
  2. 
- 期望结果：
- 实际结果：
- 影响范围：
- 根因：
- 修复方案：
- 修改文件：
- 回归风险：
- 相关历史 Bug：无 / BUG-...
- 回归测试：
- 验证命令及结果：
- 未验证项：无 / ...
- 后续注意事项：

### 补充记录或修订记录

- 日期：YYYY-MM-DD
- 类型：补充 / 调整
- 依据：用户问题描述 / 详细设计 / Git 未提交代码 / 测试结果 / 其他
- 内容：
```
